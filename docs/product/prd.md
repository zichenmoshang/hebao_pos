# 产品需求文档（PRD）

| 项 | 内容 |
|---|---|
| 产品名称 | 和宝小吃 |
| 工程名 | hebao_pos |
| 平台 | Android（专用安卓机） |
| 形态 | 离线原生 App（Flutter） |

## 1. 背景与问题

早餐店早高峰顾客排队，顾客**口述点单**，典型如"8 个肉锅贴、1 杯豆浆"。店主需要：

- 快速算出应收金额，不能心算出错
- 操作必须极快，顾客等待时间敏感
- 一天结束后想知道今天卖了多少钱、各品种卖了多少，并对照原材料支出估算赚了多少

本产品**不接入任何支付工具**，只负责算价与记账。

## 2. 目标与非目标

### 目标

1. 顾客说完需求后，店主在极短时间内（目标 3 秒内）完成点按并看到总价
2. 结账后零成本记账，快速接待下一位
3. 提供按日 / 月 / 自定义区间的经营统计
4. 记录原材料采购金额，估算毛利
5. 完全离线、免注册、打开即用

### 非目标（明确不做）

- 不接入微信 / 支付宝等支付与收款
- 不做线上点单、外卖、会员营销
- 不做库存入库与消耗管理（小店操作成本高于数据价值）
- 不做抹零凑整（顾客基本手机支付，按实价收）
- 不做按两 / 斤等单位换算（统一按个、按杯、按碗售卖）
- 早期不做多员工账号、云同步

## 3. 使用者与场景

- **使用者**：店主及其家人，高峰期多人接力操作同一台手机
- **硬件形态**：安卓机固定在台面支架上，竖屏，全天常开
- **环境特点**：嘈杂、忙碌、可能湿手，要求大按钮、强反馈、防误触

## 4. 功能需求

### 4.1 收银主页（P0，核心）

主界面自上而下：

1. **顶部栏**：菜单按钮（打开抽屉）、当日流水（金额 + 订单数）
2. **金额面板**：
   - 超大字号常驻显示当前应收金额
   - 明细行显示已点品种与数量（如"肉锅贴×8，豆浆×1"）
   - 无商品时金额显示 ¥0.0 并弱化
3. **商品网格**（弹性撑满屏幕剩余空间，无空隙）：
   - 商品来自商品管理（默认肉锅贴、素锅贴、豆浆、豆腐脑、五香蛋 5 种）
   - 三列大卡片，显示名称、单价、单位；右上角数量角标（数量 > 0 时显示）
   - 商品超出一屏时可纵向滚动；一屏内尽量让常用商品全部可见
   - **单击卡片：数量 +1，并选中该商品**（卡片描边表示选中）
   - 卡片底部「清除」：仅在该商品数量 > 0 时出现，单击直接移除该商品
   - 选中态在切换商品时跟随
4. **快捷数量区**（位于商品网格下方，固定占位、高度不跳动）：
   - 未选中商品时弱化并显示引导文案
   - 选中商品后高亮，显示当前商品名与数量
   - 头部按钮：`−`（减一个）、`0`（数量设为 0）、`⌨`（打开数字键盘）
   - 快捷数字：`2 3 4 5 6 7 8 9`，语义为**"将该商品设为 N 个"**（不是加 N）
5. **底部操作**：`清零`（文字危险色，撤销整单）、`结账下一位`（绿色主按钮）

**关键交互规则**：

- 数量变化与金额刷新必须**零延迟**，不做数值过渡动画
- 单击商品卡片触发一次**轻微震动**；结账触发稍明显震动
- 结账后：顶部弹出 toast「已记账 ¥X，已清零」，数据立即归零，下一位第一次点击立即生效
- toast 位于屏幕最顶端，不拦截触摸事件，约 1.5 秒自动消失
- 清零与结账均**不做二次确认弹窗**，仅靠颜色和位置区分
- 支持从屏幕左缘右滑打开抽屉，左上角菜单按钮同样可打开

### 4.2 数字键盘弹层（P0）

- 入口：快捷区 `⌨`；正式版支持长按商品卡片直接唤起
- 底部弹出大数字键盘：0~9、C（清空输入）、确定
- 输入为**替换式**：默认带入当前数量，确定后"设为 N"
- 用于超过 9 的例外大单或任意精确数量

### 4.3 商品管理（P0，低频）

入口：抽屉 → 设置 → 商品管理。

店主可自主维护商品目录，不再固定为 5 种。支持**新增、改名、改单价、改单位、商品图片、停用、手动排序**。

- **新增 / 编辑**：商品名（必填、不允许重名）、单价（分）、单位、商品图片
  - 单位提供固定选项「个 / 杯 / 碗 / 瓶 / 份」，并支持「自定义」输入任意文字；不做单位换算
- **商品图片（选填）**：
  - 支持**拍照或从相册选择**；图片压缩后存为应用文档目录下的本地文件，数据库仅存文件路径（完全离线，不用网络图床）
  - 未设置图片的商品显示占位样式（色块 + 名称首字）
  - 更换商品图时删除旧图片文件；停用保留图片以便重新启用，仅在未来物理删除商品时才清理图片文件
- **停用**：删除一律走停用（`is_active = 0`），商品从收银网格消失，但历史订单已保存商品名快照、统计销量不受影响
  - 管理页可查看已停用商品并支持重新启用
- **排序**：在管理页手动拖拽排序，收银网格按该顺序展示；常用商品建议排在前、控制在首屏
- 主界面不放置任何编辑入口，防止高峰期误改价 / 误删

**收银页网格适配**：

- 卡片为「**上图下文**」：上半部分显示商品图片（无图显示占位），下半显示名称、单价、单位；保留数量角标、选中描边、卡片底部「清除」
- 商品超出一屏时网格可**纵向滚动**查找（低频商品滚动可接受）；一屏内仍为三列大卡片
- 网格高度仍占据金额面板与快捷数量区之间的弹性空间

### 4.4 成本记录（P0）

入口：抽屉 → 成本记录。

只记采购金额，**不记库存、不记消耗、不挂商品单位成本**。

**页面结构**（自上而下）：时间筛选栏 → 区间采购总额 → 采购流水列表；右上角提供「类目管理」入口。

- 时间筛选：复用统计页的按日 / 按月 / 自定义模式与中文日期选择弹窗，切换区间后总额与列表同步刷新
- 记录一笔：**金额 + 类目（必选）+ 日期（默认当天）+ 备注（选填）**；记录表单的类目选择处也可快速新建类目
- 流水列表：仅列当前区间，按日期分组、倒序，每条显示类目、金额、日期、备注
- 记错处理：支持**滑动删除**（二次确认）与**点击进入编辑**（金额 / 类目 / 日期 / 备注均可改）

**类目管理**（如猪肉、面粉、粉丝）：

- 支持新增 / 改名 / 删除；类目名唯一，重名拦截
- 删除一律走**软删除（is_active）**：从新建时的选择列表隐藏，但历史流水仍显示原名并照常计入区间汇总与类目分布

### 4.5 统计（P1）

入口：抽屉 → 统计。

> 实现进度：销售侧（时间筛选 / 概览 / 趋势 / 单品 / 订单明细）与成本毛利均已接入。

统计基于历史订单聚合，需先完成数据落库（见 [../architecture/database.md](../architecture/database.md)）：

- 启用 Drift，结账在**单事务**内写入 `orders`（总额 + 结账时间戳）与全部 `order_items`（商品、名称快照、成交单价、数量、行小计），成功后再清空内存订单
- 首次启动写入 5 个商品种子数据，商品改为从数据库读取
- 收银页顶部"当日流水"改为数据库实时聚合
- 统一存本地时间戳，按设备本地日期切分（单店无时区问题）

**页面结构**（自上而下）：时间筛选栏 → 概览指标（销售 + 成本毛利两行）→ 每日营业额趋势 → 单品销量排行 → 采购类目分布 →「区间订单明细」入口。

- 时间筛选：按日、按月、自定义起止日期
  - 按日为当日 0 点 ~ 次日 0 点（半开区间）；按月为月初 0 点 ~ 下月 1 日 0 点；自定义含首尾
  - 切换区间后页内所有模块同步刷新
- 概览指标：
  - 销售行：营业额、订单数、客单价（营业额 ÷ 订单数；无单显示 ¥0.0）
  - 成本毛利行：采购额、毛利、毛利率
    - 毛利 = 区间营业额 − 区间采购额；毛利率 = 毛利 ÷ 营业额（营业额为 0 时显示「—」）
    - 采购按"发生日期"计入、不按实际消耗，集中采购会造成单月波动，模块标注「仅供参考」
- 每日营业额趋势：
  - 折线图展示区间内每日营业额，无数据日计为 0；横轴日期、纵轴金额
  - **按日只有一个点，不展示趋势图**；不做柱状切换
- 单品维度：各品种销量、销售额、销售额占比排行，区间内未售出品种不展示
  - **点击某商品行展开其区间内每日销量明细**，再次点击收起
- 采购类目分布：
  - 环形占比图展示区间内各类目采购额占比，旁列各类目金额与占比；无采购的区间显示空状态
  - 已软删除的类目仍计入分布（历史采购不丢）
- 区间订单明细：
  - 仅列出当前筛选区间内订单，按时间倒序；每条显示下单时间、总额，可展开查看商品明细
  - 支持滑动删除错单：级联删除其明细，**删除前二次确认**，删除后统计各模块自动重算

**实现要点**：

- 依赖：`fl_chart`（折线图与环形占比图）、`intl`（日期格式化）、`calendar_date_picker2`（自定义日期选择弹窗）、`flutter_localizations`（SDK，全局中文本地化）
- 本地化：`MaterialApp` 固定 `locale: zh_CN`，注册 Material / Widgets / Cupertino 三套 delegate；日期选择器周一开头、中文星期，头部「N月 / yyyy年」中文标签，不显示下拉箭头
- 折线图不做贝塞尔平滑（`isCurved: false`），避免稀疏尖峰数据下曲线下冲 / 上冲失真；显式 `minX/maxX` 绑定范围并 `clipData` 裁剪；纵轴间隔从「好读」候选值（0.5/1/2/5/10… 元）选档，最大值取整到该间隔整数倍
- 复用索引：`idx_orders_created_at`（区间营业额 / 订单数 / 每日趋势）、`idx_items_product_id`、`idx_items_order_id`（单品聚合与明细）、`idx_cost_occurred_on`、`idx_cost_category`（区间采购总额与类目分布）
- 数据刷新：删除错单或新增 / 改 / 删采购后，销售与成本相关 provider 一并 invalidate，概览、趋势、类目分布同步重算
- 验收：`flutter analyze` 通过；结账 / 记账后杀进程重开数据不丢；各区间切换数字、图、排行一致；删除错单或改删采购后全部同步更新；软删类目不在选择列表出现但历史汇总仍在

后续迭代：数据导出（已实现，单个 Excel 含多工作表）。

### 4.6 设置（P0/P1）

入口：抽屉 → 设置。以卡片分组呈现：`通用`（震动、屏幕常亮）、`数据`（导出、商品管理）。

| 设置项 | 默认 | 说明 |
|---|---|---|
| 震动反馈 | 开 | **一个总开关**，控制全部震动（点按、结账、新增/删除成本、删除错单）；关闭后各处均不触发 |
| 屏幕常亮 | 常亮 | 可选 常亮 / 1 / 2 / 5 分钟无操作后息屏 |
| 数据导出（P1） | - | 按所选区间导出 Excel，用于备份与对账 |
| 商品管理 | - | 见 4.3：维护商品目录 |

**持久化**：使用 `shared_preferences` 保存少量设置项（不进数据库、不随业务数据导出）；经统一的设置 provider 读写，重启后保留。

**屏幕常亮口径**：

- 仅在收银页（全天常开主界面）生效，使用 `wakelock_plus`
- 「常亮」持有 wakelock；选 X 分钟时，检测到 X 分钟无操作即**释放 wakelock**，随后跟随系统超时息屏（非在 X 分钟精确主动关屏，那需要设备管理员等高权限）；再次操作重新计时
- 息屏点亮后直接回到收银页，不设锁屏密码（店内专用机）

**数据导出（Excel）**：

- 导出前先选时间区间（自定义起止日期）；空区间提示无可导出数据
- 生成**单个 xlsx**，含三个工作表：
  - 订单汇总：订单号、下单时间、总额（元）
  - 订单明细：订单号、商品名、单价（元）、数量、行小计（元）
  - 成本采购：日期、类目、金额（元）、备注
- 某类数据为空时对应工作表省略；金额按「元」以数值写入；文件名含区间日期
- 通过 `share_plus` 调系统分享面板，由用户微信发送或另存

## 5. MVP 范围

- **P0**：连点计价 + 快捷数量 + 数字键盘、结账记账与清零、当日流水、商品管理（增改 / 改价改单位 / 停用 / 排序）、原材料金额记录与类目管理、设置（震动、常亮）
- **P1**：统计页（日 / 月 / 自定义、单品、趋势、成本毛利与类目分布）、数据导出（Excel）
- **P2**：云备份 / 换机同步、多员工、套餐组合

## 6. 设计原则

1. **零思考**：店主不记单价、不心算
2. **超大点击区**：忙乱、湿手也能准确点按
3. **总价常驻且巨大**：任何时刻一眼可见
4. **单手 / 单点闭环**：点单 → 看价 → 结账 → 清零，路径最短
5. **破坏性操作集中且弱化**：高频区不放删除按钮
6. **反馈即时但不阻挡**：震动确认手感，toast 不挡操作
