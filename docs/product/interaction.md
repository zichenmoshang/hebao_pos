# 交互说明

本文档记录收银主页的交互细节与设计决策。界面原型图见 [../images/](../images/)。

## 1. 一笔订单的操作路径

### 普通数量（1~9）

以"7 个素锅贴 + 1 杯豆浆"为例：

1. 点一次「素锅贴」卡片 → 数量变 1，卡片出现选中边框
2. 点快捷数量区「7」→ 素锅贴数量直接设为 7
3. 点一次「豆浆」卡片 → 豆浆 1 杯（同时选中切到豆浆，边框跟随移动）
4. 查看顶部金额
5. 点「结账下一位」→ 震动反馈、记账、界面归零（无 toast）

### 小数量（1~4，最高频）

直接连点卡片即可，无需使用快捷区。例如"肉锅贴×2"就是点两下。

### 大数量（超过 9 的例外单）

1. 点一次商品卡片
2. 点快捷区头部右侧 `⌨` 打开数字键盘
3. 输入数量 → 确定（「设为 N」）

### 移除某个已点商品

- 点快捷区头部「清除」→ 当前选中商品数量清零、商品行移除
- 同时取消选中：该卡片边框还原为默认灰色描边，快捷区回到「先点商品卡片」引导态

### 布局顺序

自上而下为：顶部栏 → 金额面板（仅金额，右对齐）→ 商品网格（弹性撑满）→ 快捷数量区 → 结账 / 清零。快捷数量区紧贴商品网格下方，点卡片后手指不移位即可设数量。

## 2. 快捷数量区设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 触发方式 | 卡片点击即选中并 +1，快捷区常驻可用；**无任何长按操作** | 高频紧迫场景下长按不符合直觉，点击是唯一交互 |
| 数字语义 | **设为 N**，而非 +N | 顾客口述的是总数；已点 3 个改 5 个时，点 5 即纠正，无需心算差值 |
| 数字范围 | 2~9 八枚按键 | 顾客早餐基本不超过 10 个；2~9 覆盖绝大多数订单 |
| 单品清除 | 头部「清除」按钮：数量清零、移除商品并取消选中 | 语义明确为「清除当前商品」；取消选中让边框状态与数据一致 |
| 大数量 | 头部右侧 `⌨` 打开底部数字键盘 | 超过 9 的例外单才需要，入口弱化不占主网格 |
| 布局 | 固定占位，未选中时弱化（50% 透明）显示引导文案 | 界面高度不跳动，避免视觉跳动干扰 |

## 3. 动效与反馈

| 场景 | 反馈 | 说明 |
|---|---|---|
| 按下商品 / 数字按钮 | 轻微缩放（约 90ms）+ 轻震 | 手指抬起即结束，确认"按到了" |
| 结账成功 | 中震 + 界面归零 | 不弹 toast，靠震动与界面复位确认 |
| 金额 / 数量变化 | 无动画，立即刷新 | 数值过渡会造成延迟感 |
| 角标 | 无弹跳 | 去掉装饰性动画 |

震动为总开关（设置 → 震动反馈）；并跟随系统"移除动画"无障碍设置。

### 选中边框与抗锯齿

- 选中态 = 当前点击的商品：1 逻辑像素青色描边（`AppColors.selected`）；未选中为灰色描边（`AppColors.border`），两种状态线宽一致、靠颜色区分。
- 数量 > 0 时卡片底部另有青色带（`AppColors.activeBand`）和右上角数量角标，与「选中边框」是相互独立的两个状态。
- 为消除圆角毛边：圆角半径、描边宽度、结账按钮高度均经 `UiScale.snap()` 对齐到物理像素网格；描边不用 `PaintingStyle.stroke`，而是绘制外、内两个填充 RRect 的 `evenOdd` 差集形成环，填充路径覆盖率更准确。
- 模拟器软件渲染（SwiftShader）下毛边会被放大；开发时 AVD Graphics 选 Hardware - GLES，最终效果一律以真机 profile/release 模式为准。

## 4. 防误触策略

- 商品卡片整块为点击区，放大命中面积
- 卡片上只有"+1 / 选中"一个点击动作；移除商品集中到快捷区头部「清除」，数量修改用 2~9 按键
- `清零` 为描边按钮位于左下，与青色实心主按钮「结账」明确区分
- 不做二次确认弹窗，避免拖慢高峰期速度
- 单价管理 / 改价等低频操作全部收入抽屉，主界面无入口

## 5. 抽屉

- 打开：左上角 `☰`，或屏幕左缘右滑
- 内容：统计、成本记录、单价管理、设置
- 目的：收银页不使用底部 Tab，整块屏幕留给计价
- 点击遮罩关闭
